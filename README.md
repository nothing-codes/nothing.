# nothing.

Лендинг для заказной сборки компьютеров.

Тёмная минималистичная тема, WebGL-анимация на фоне, плавные переходы. Одностраничник с секциями: почему мы, сборки, FAQ.

## Стек

- **Next.js 15** — App Router
- **TypeScript** — строгая типизация
- **Tailwind CSS v4** — утилитарные стили
- **Framer Motion** — анимации появления
- **WebGL** — нейронный вихрь на фоне (кастомный шейдер)
- **Lucide** — иконки

## Требования

- Node.js 20+
- npm 10+

```bash
git clone https://github.com/username/nothing-pc.git
